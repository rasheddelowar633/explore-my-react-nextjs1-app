1. Project Name ;(FITLOG), explore-my-react-nextjs1-app.
2. FITLOG is your ultimate fitness companion. Discover workouts, create personalized fitness plans, save your favorite exercises, and stay motivated to achieve your fitness goals. Build healthy habits and become stronger every day with FITLOG.
3. Technologies Used
    - Next.js — React framework for building pages and routing.
    - React.js — Building reusable UI components.
    - Tailwind CSS — Styling and responsive design.
    - JavaScript (ES6+) — Application logic and interactivity.
    - Context API — Managing workout plans and saved workouts.
    - LocalStorage — Saving workout data in the browser.
    - React Toastify — Displaying success and notification messages.
    - REST API — Fetching workout data from an external API.
    - Git & GitHub — Version control and source code management.
4. FITLOG – 5 Key Features
    a. Workout Library – Explore a collection of workouts with detailed information.
    b. Workout Details – View individual workout details, descriptions, and exercise information.
    c. My Plan – Add and manage your personal workout plans.
    d. Save Workouts – Save your favorite workouts and remove them whenever you want.
    e. Responsive Design – Enjoy a smooth experience across desktop, tablet, and mobile devices.
